CNN Image Classification on CIFAR-10

A convolutional neural network that classifies 32×32 color images across 10 categories.

Python · TensorFlow · Keras

Purpose

Build a model to classify images into ten predetermined categories, then iterate on architecture and training choices to reduce loss and improve accuracy. Python was the implementation language of choice for its mature machine-learning ecosystem (TensorFlow / Keras) and strong tooling for data access and transformation.

Dataset

The model was trained on the CIFAR-10 dataset: 60,000 color images at 32×32 resolution, split into 50,000 training images and 10,000 test images. The training data is distributed across five batches of 10,000 images; the test batch contains exactly 1,000 randomly selected images per class.

Data Normalization

Pixel values are scaled to the [0, 1] range by dividing by 255. This keeps inputs on a consistent, small scale, which helps gradient descent converge. 

(train_images, train_labels), (test_images, test_labels) = datasets.cifar10.load_data()

train_images, test_images = train_images / 255.0, test_images / 255.0

Convolutional Base

Because the input is image data, the model uses a Convolutional Neural Network (CNN). After experimenting with several depths, the final base uses three Conv2D layers with two MaxPooling2D layers interleaved between them. The CNN accepts 32×32 RGB tensors (32×32×3) and uses ReLU as the activation throughout the convolutional layers. 

import tensorflow as tf
from tensorflow.keras import datasets, layers, models

model = models.Sequential()
model.add(layers.Conv2D(32, (3, 3), activation='relu', input_shape=(32, 32, 3)))
model.add(layers.MaxPooling2D((2, 2)))
model.add(layers.Conv2D(64, (3, 3), activation='relu'))
model.add(layers.MaxPooling2D((2, 2)))
model.add(layers.Conv2D(64, (3, 3), activation='relu'))

The width and height dimensions shrink as you go deeper into the network. The number of output channels for each Conv2D layer is controlled by the first Conv2D layer, which holds the input image configuration.

Dense Head

Two Dense layers sit on top of the convolutional base. The 3D feature map from the last convolution is first flattened into a 1D vector. The final layer has 10 outputs — one per class — and uses softmax to produce a probability distribution. 

model.add(layers.Flatten())
model.add(layers.Dense(64, activation='softmax'))
model.add(layers.Dense(10))

Compile and Train

Adam was chosen as the optimizer — generally a strong default among adaptive optimizers. The loss is sparse categorical cross-entropy on logits. Training runs for 10 epochs, validating on the held-out test set after each epoch. 

model.compile(
    optimizer='adam',
    loss=tf.keras.losses.SparseCategoricalCrossentropy(from_logits=True),
    metrics=['accuracy'],
)

history = model.fit(
    train_images, train_labels,
    epochs=10,
    validation_data=(test_images, test_labels),
)

Design Experiments

The final architecture is the result of several iterations on layer count, training duration, activation choice, and regularization. The table below summarizes what was tried and what stuck:

Knob What was tried What stuck and why
Layer count Different numbers of Conv2D / pooling layers 3 Conv2D + 2 MaxPool — adding more layers did not measurably improve accuracy or loss
Epochs 3–4, 10, 20, and 25 10 — fewer than 10 underfits visibly; 20–25 doesn't justify the extra training time
Final-layer activation softmax vs. ReLU on the output Dense layer softmax — accuracy was similar, but softmax matches the standard practice for class probabilities
Dropout Dropout regularization at varying rates Skipped — dropout did not meaningfully improve accuracy or overfitting in this setup
