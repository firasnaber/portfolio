Projects

gRPC-Based Distributed File System
C++ · gRPC · concurrency · code available on request

A distributed file system using gRPC streaming RPCs for chunk-based file transfer across a client–server architecture. Includes a multi-client synchronization protocol with CRC checksums and timestamp-based conflict resolution, asynchronous callback handling via completion queues, and thread-safe concurrency control using mutexes, condition variables, and server-side write locks.

Multithreaded HTTP Proxy with Shared-Memory Cache
C · pthreads · POSIX IPC · code available on request

A high-performance HTTP proxy using pthreads and libcurl to concurrently fetch and stream content to multiple clients. Implements an IPC-based caching layer with POSIX shared memory, message queues, and semaphores; chunked data transfer via mmap-backed shared memory to minimize redundant copies; and a synchronized segment pool to prevent race conditions under concurrent load.

EvoTSP: Genetic Algorithm Visualizer for the Traveling Salesman Problem
JavaScript · Node.js · AWS (EC2, Lambda, DynamoDB, IAM) · Leaflet · GitHub

A Traveling Salesman visualizer with a Node.js backend deployed on AWS (EC2, Lambda, DynamoDB, IAM). A genetic algorithm computes near-optimal routes between user-selected map points, with results rendered dynamically on an interactive Leaflet map as the population evolves across generations. AWS Lambda APIs handle route computation and data flow between the backend and frontend.

Genetic Algorithm for the 0-1 Knapsack Problem
Python · genetic algorithms · simulated annealing · GitHub

A Python implementation of a genetic algorithm to solve the 0-1 Knapsack problem, with configurable selection (tournament, roulette), crossover (single-point, multi-point), and mutation (bit-flip, swap) operators. Handles infeasible solutions via penalty-based fitness adjustment and preserves top performers across generations through elitism. Includes a simulated-annealing baseline for comparison against the GA's near-optimal results.

CNN Image Classification on CIFAR-10
Python · TensorFlow / Keras · GitHub

A convolutional neural network for classifying CIFAR-10 images across 10 categories, built with TensorFlow and Keras. The architecture stacks three Conv2D layers with interleaved max-pooling and two dense layers (~123K trainable parameters), trained with Adam and sparse categorical crossentropy. Achieved ~72% test accuracy after ten epochs. Includes experiments with layer depth, epoch count, dropout regularization, and softmax vs. ReLU output activations to investigate accuracy–overfitting tradeoffs.

DoorBoard: Faculty Announcement Web App
Angular · TypeScript · Java · MongoDB · Auth0 · Docker · co-authored coursework · GitHub

A full-stack web application built with a team during a software-design course, intended as a digital alternative to the sticky notes professors leave on their office doors. An Angular + TypeScript frontend communicates with a Java backend and a MongoDB database; Auth0 handles per-user authentication; QR-code generation lets visitors scan their way to a faculty member's announcement page. The system supports note expiration, pinning, favoriting, and is containerized with Docker for deployment on DigitalOcean.
