Projects

gRPC-Based Distributed File System
C++ · gRPC · concurrency · code available on request

A distributed file system using gRPC streaming RPCs for chunk-based file transfer across a client–server architecture. Includes a multi-client synchronization protocol with CRC checksums and timestamp-based conflict resolution, asynchronous callback handling via completion queues, and thread-safe concurrency control using mutexes, condition variables, and server-side write locks.

Multithreaded HTTP Proxy with Shared-Memory Cache
C · pthreads · POSIX IPC · code available on request

A high-performance HTTP proxy using pthreads and libcurl to concurrently fetch and stream content to multiple clients. Implements an IPC-based caching layer with POSIX shared memory, message queues, and semaphores; chunked data transfer via mmap-backed shared memory to minimize redundant copies; and a synchronized segment pool to prevent race conditions under concurrent load.
